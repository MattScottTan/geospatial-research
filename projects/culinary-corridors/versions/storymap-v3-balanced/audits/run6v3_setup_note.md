# Run 6 v3 Setup Note — Regional Balance and Non-Asia Diagnostic Expansion

## Purpose
Run 6 v3 revises the expanded ArcGIS StoryMap package so the submission does not read as an Asia-only cuisine project. The prior Run 6 v2 structure was analytically correct, but the presentation risked over-emphasizing East/Southeast Asia because the strongest focused case, topographic relief map, and most vignettes were all Asian or Asia-adjacent.

## What changes
This run preserves the approved project hierarchy while making the presentation more balanced:

1. The global discovery section is expanded and made more substantive.
2. East/Southeast Asia is reframed as a focused case selected from the global screen, not as the preselected subject of the project.
3. The Iberian/Atlantic-Pacific material is made mandatory as a non-Asia diagnostic comparison.
4. A direct note explains why Europe/Atlantic-linked material is included diagnostically but not elevated to the same inferential status as East/Southeast Asia.
5. The build order, paste blocks, figure manifest, callouts, audits, and QA checklist are updated so Matthew can build the regionally balanced StoryMap in ArcGIS.

## What remains unchanged
- The core thesis remains: cuisine similarity is spatially structured but not reducible to distance.
- Global results remain a discovery screen.
- East/Southeast Asia remains the primary focused inference case.
- Iberian/Atlantic-Pacific remains a required secondary/diagnostic case.
- The Run 5 relief map remains spatial context, not a causal topographic model.
- The residual bridge index remains the strongest geospatial-only insight.

## What must not be overclaimed
The revised StoryMap must not imply a full Europe-specific analysis, must not claim causality from migration/trade/colonialism/topography, and must not treat the recipe corpus as globally representative. Non-Asia material is included to show the global method and diagnostic breadth, not to pretend the same level of focused inference has been established everywhere.
