# One-Page Submission Summary

## Title
**Culinary Corridors: Mapping Food Similarity, Spatial Residuals, and Regional Exchange**

## Project description
Culinary Corridors uses GIS to ask when cuisine similarity follows geographic distance and when it exceeds distance-based expectation. The project represents cuisines as filtered ingredient profiles, calculates pairwise similarity, anchors cuisine labels to approximate geographic locations, fits a distance baseline, and maps positive residuals as candidate culinary corridors.

## Research question
**When does cuisine similarity follow geographic distance, and when does it follow corridors, bridges, regions, or boundaries instead?**

## Core thesis
Cuisine similarity is spatially structured but not reducible to distance. By modeling food similarity as residual geography, this project identifies where cuisine follows distance, where it breaks distance, and which places become bridge nodes in a spatial network of culinary resemblance.

## Main evidence sequence
1. Cuisine labels are converted into filtered ingredient profiles.
2. Pairwise cuisine similarity is compared with geographic distance.
3. Positive residuals become candidate culinary corridors.
4. The global model is treated as a discovery screen.
5. East/Southeast Asia is used as the primary focused case.
6. A Run 5 relief-context map makes the focused corridor visually legible.
7. A residual bridge index turns pairwise residuals into mapped place-level roles.

## Strongest Fisher contribution
The project is not simply mapping food. GIS produces the central evidence by comparing cuisine similarity to spatial expectation, mapping residuals, and identifying bridge roles that cannot be derived from ingredient vectors alone.

## Claim discipline
The project does not claim that the recipe corpus represents all world cuisine or that migration, trade, colonialism, maritime movement, or terrain caused the observed similarities. It identifies spatial associations and candidate corridors that can guide future inquiry.
