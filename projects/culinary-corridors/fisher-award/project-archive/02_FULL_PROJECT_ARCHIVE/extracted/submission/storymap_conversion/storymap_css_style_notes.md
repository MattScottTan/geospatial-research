# ArcGIS StoryMap Style Notes

These are practical design notes for building the StoryMap. They do not require custom CSS.

## Overall style
- Use a clean, restrained theme. The figures already carry visual complexity.
- Prefer high-contrast text on simple backgrounds.
- Use section dividers only where the argument turns: method, primary case, topographic context, bridge index, limitations.
- Keep body text short: usually 1–3 paragraphs between figures.

## Figure sizing
- Use full-width image blocks for the six required figures.
- Enable image expansion if ArcGIS offers it, especially for the hero map, method plot, topographic corridor map, and bridge-index figure.
- If a figure appears too cropped in a sidecar, switch to a full-width image block.
- The Run 5 topographic map should be large; it is meant to be visually striking.

## Section rhythm
1. Short setup text.
2. Figure.
3. Caption.
4. One-sentence “what to notice” callout.

## Color and typography
- Do not add extra decorative colors; preserve the figure palette.
- Use bold sparingly for claim hierarchy and key terms: residual, discovery, focused case, bridge index.
- Keep captions smaller than body text but readable.

## Recommended ArcGIS block choices
- Title / hero: Cover.
- Method and focused cases: Image block or sidecar.
- Run 5 topographic map: full-width image block.
- Callouts: quote block, separator text, or emphasized paragraph.
- Sources/PDF backup: text block plus button/link.

## Mobile-readability check
- Confirm that dense maps are still legible when opened/expanded.
- If mobile captions become too long, place source notes in the final source panel and keep per-figure captions shorter.
