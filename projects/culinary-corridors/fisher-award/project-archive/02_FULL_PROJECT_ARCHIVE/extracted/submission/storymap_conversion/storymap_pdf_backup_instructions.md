# StoryMap PDF Backup Instructions

## PDF to use
Primary backup PDF:

`report/final_complete/culinary_corridors_complete_final_report.pdf`

## Where to mention it
Add the PDF link in the final StoryMap section titled **Sources, Methods, and Full Report**.

Suggested text:

> The complete PDF report contains the full methods, data notes, source limitations, figure documentation, and claim audit. If the submission form allows supporting materials, this report should be submitted or linked as the technical backup to the StoryMap.

## If the Fisher form accepts both a URL and file upload
- Submit the StoryMap URL as the main project.
- Upload or link the PDF as supporting documentation.
- Use the one-page submission summary for the form description.

## If the Fisher form accepts only one URL
- Submit the StoryMap URL.
- Include a public/shareable PDF link in the final StoryMap section.
- Confirm the link opens in a private/incognito browser.

## If the Fisher form accepts only one file
- Submit the PDF report.
- Put the StoryMap URL prominently on the first page or in the opening note if possible.

## Link hygiene
- Use a public/shareable link, not a local `sandbox:/` path.
- Test from a browser where you are not logged in.
- Check that the PDF opens on desktop and mobile.
