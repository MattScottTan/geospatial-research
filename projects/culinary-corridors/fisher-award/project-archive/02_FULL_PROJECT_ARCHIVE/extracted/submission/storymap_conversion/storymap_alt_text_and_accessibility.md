## General accessibility recommendations
- Use short paragraphs; avoid dense blocks of text.
- Keep captions visible and concise.
- Use heading levels consistently.
- Test the StoryMap on a laptop and a phone.
- Check that labels remain readable at StoryMap image scale.
- Add descriptive alt text to every uploaded image where the ArcGIS editor allows it.
- Do not use color as the only signal. Captions should explain blue/orange/teal lines and other encodings.
- If the cover image crop hides important map details, use a simpler cover and place the full figure below the introduction.
