# PDF Backup and Submission Note

## Where to place the PDF link

Place the PDF backup link in the final StoryMap section titled **Technical report and PDF backup**. If ArcGIS allows a button block, use a button labeled **Open the full technical PDF report**. If not, insert a normal hyperlink in the final paragraph.

## Recommended language

This StoryMap is the primary map-led Fisher submission. A complete technical PDF is available as backup, documenting the data pipeline, residual model, focused cases, figure sequence, limitations, and source notes.

## If the form accepts both StoryMap and PDF

Submit the StoryMap URL as the main project and attach or link the PDF as supporting documentation.

## If the form accepts only one URL

Submit the StoryMap URL. In the StoryMap, include the PDF backup link in the final section and mention it in the submission notes if a notes field is available.

## If the form accepts only one file

Submit the PDF report and place the StoryMap URL prominently near the beginning of the PDF or in the submission notes.

## Manual QA

Before submission, open the StoryMap and the PDF link in a private/incognito browser. Confirm that the PDF loads without requiring local file access or private credentials.
