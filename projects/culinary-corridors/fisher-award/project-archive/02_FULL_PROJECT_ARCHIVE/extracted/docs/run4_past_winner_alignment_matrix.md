## Best-fit archetype
Culinary Corridors is a hybrid of:

1. **Computational GIS / spatial statistics:** distance baseline, residual modeling, bridge-index metric.
2. **Historical/cultural reconstruction:** cuisine similarity as candidate evidence for exchange geographies.
3. **Critical cartographic argument:** maps transform cultural data into spatial evidence.

## Key gap relative to previous winners
The largest gap is not topic novelty; it is judge-visible spatial necessity. A judge must not see the project as food data with maps. Run 4 therefore makes the residual geography and bridge roles the core visual evidence.

## Patterns not to copy
- Do not add remote sensing or ML simply because recent winners used them.
- Do not turn the project into a disaster, conflict, or risk project.
- Do not over-design maps at the expense of model transparency.
- Do not claim historical causation without explicit migration/trade/colonial covariate modeling.
