# Expanded StoryMap Final QA Checklist

## Before building

- [ ] Create an ArcGIS StoryMap shell titled **Culinary Corridors**.
- [ ] Upload figures in the order listed in `storymap_expanded_figure_manifest.csv`.
- [ ] Keep `storymap_expanded_build_order.md` open while building.
- [ ] Keep the section paste-block directory open and paste one section at a time.

## During building

- [ ] Use the hero figure only as a cover if it crops cleanly; otherwise place it as a full-width image in the global discovery section.
- [ ] Place the method figure before the first focused case.
- [ ] Place the Run 5 topographic map immediately after the East/Southeast Asia focused-case map.
- [ ] Place the residual bridge-index figure as a major Fisher contribution, not as an appendix.
- [ ] Use the secondary/limitations figure near the end.
- [ ] Use the optional Run 5 inset only if it improves clarity.

## Claim safety

- [ ] The global screen is described as discovery, not proof.
- [ ] East/Southeast Asia is described as the primary focused case.
- [ ] The Run 5 relief map is described as spatial context, not causal terrain analysis.
- [ ] Residual links are not called historical routes.
- [ ] The text does not claim migration, trade, colonialism, maritime routes, or topography caused the results.
- [ ] The recipe corpus is described as a platform-mediated proxy, not a representative census.
- [ ] Cuisine labels are described as approximate cultural-geographic anchors, not exact nation-states.

## Accessibility and display

- [ ] Every figure has a caption.
- [ ] Every figure has meaningful alt text.
- [ ] Text and figure labels are legible on desktop.
- [ ] Text and figure labels are legible on mobile or tablet preview.
- [ ] Long sections are broken into short paragraphs or sidecar panels.
- [ ] Color/line differences are explained in captions, not left implicit.

## Sources and backup

- [ ] Sources/methods/reproducibility section is included.
- [ ] PDF backup link is included in the final section if a public URL is available.
- [ ] PDF link opens in a private/incognito browser.
- [ ] No local-only file paths appear in the published StoryMap.

## Final submission checks

- [ ] Preview the StoryMap from beginning to end.
- [ ] Open the shared StoryMap link in a private/incognito browser.
- [ ] Confirm the title, author name, and Fisher context are correct.
- [ ] Check that no placeholder text remains.
- [ ] Save a screenshot or confirmation after submitting.
