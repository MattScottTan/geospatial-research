# Run 6 Setup Note — ArcGIS StoryMap Conversion Package

Created: 2026-05-01

## Purpose
Run 6 converts the completed **Culinary Corridors** Fisher Award project into a copy-paste-ready ArcGIS StoryMap package. The goal is not to add analysis, figures, or claims. The goal is to make the final submission easy to build in ArcGIS StoryMaps: exact section order, exact text to paste, figure placement notes, captions, alt text, callout boxes, source/limitations language, PDF backup instructions, and pre-submission QA.

## Inherited scope
The approved scope remains:

1. **Global discovery screen** — used to identify candidate residual culinary corridors.
2. **East/Southeast Asia primary case** — the strongest focused inference case.
3. **Run 5 topographic corridor context** — relief/coastal/spatial context for the focused case, not causal proof.
4. **Residual bridge-index insight** — the strongest geospatial-only contribution.
5. **Iberian/Atlantic-Pacific secondary/diagnostic case and sensitivity** — useful for caution and limits, not primary proof.

## Final StoryMap sequence
1. Title / hero
2. Research question and problem
3. Data and caveats
4. Spatial method / residual logic
5. Global discovery screen
6. East/Southeast Asia primary case
7. Run 5 topographic corridor context
8. Residual bridge-index / geospatial-only insight
9. Secondary/diagnostic case and sensitivity
10. Limitations and claim discipline
11. Conclusion and contribution
12. Sources / PDF backup note

## Non-goals
- No new statistical or geospatial analysis.
- No new figures.
- No hosted/published StoryMap creation without user authorization.
- No causal claims about migration, trade, colonialism, maritime exchange, or terrain.
- No claim that the recipe corpus represents all cuisines.

## Immediate risks
- The StoryMap could become too text-heavy; keep sections concise and figure-led.
- The topographic relief map could be overread as causal; explicitly call it context.
- The global map could be overread as proof; explicitly call it discovery.
- Source and limitation notes must be visible, not hidden.
