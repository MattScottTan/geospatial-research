# Visualization and Cartographic Communication Storybook

## Criterion definition

Fisher visualization strength is not just visual polish. The winning pattern is a cartographic or narrative package that makes the project’s argument easy to grasp, memorable, and proportionate to the topic. Different media can succeed, but the best accessible winners make the analytical claim legible at a glance.[P1][P2][P4][P5][P8]

## Evaluation signals

- The title and first visual immediately communicate what the project is about.[P1][P2][P4][P5][P8]
- The chosen medium fits the argument: StoryMap when sequencing matters, poster/graphic object when one visual punch matters.[P1][P2][P4][P8]
- The maps are not overloaded; they carry a claim rather than a decorative surface.
- The narrative flow helps the reader understand why the maps matter.[P1][P4][P5][P8]
- Cartographic clarity supports judgment, not just aesthetics.[P2][P5][P8]

## Winner case studies

### Top-tier accessible case

- **Emilio Sempris (5/5 in the current matrix):** Emilio is the clearest communication winner in the accessible set because the project is built as a 3D poster/infographic object. The visual package is inseparable from the claim about jurisdiction-level wildfire prioritization.[S1][P8]

### Strong 4/5 cases

- **Aanchal Chopra (4/5):** Aanchal’s project benefits from a title that immediately signals both the user problem and the climate condition. The route-based StoryMap framing likely helps judges see the practical claim quickly.[S4][P1]
- **Shane Rice (4/5):** *Finding Anfal* is a strong communication title, and the StoryMap format is well suited to historical-geographic reconstruction. The accessible evidence suggests clear narrative framing even if design specifics are less visible in the snippet.[S5][P2]
- **Beatrice Youd (4/5):** Beatrice’s StoryMap appears to communicate through question-led sequencing — impacts on forest loss and accessibility — which is a useful pattern for readable analytical storytelling.[S6][P4]
- **Bora Ju (4/5):** Bora’s project uses temporal staging and classified maps to make urban change legible. The communication strength comes from making pre/post-war change interpretable rather than purely technical.[P5]

### Communication lesson from a constrained case

- **Dev Patel (3/5 in the current matrix):** Dev’s public project page is analytically rich, but the recoverable public evidence foregrounds substance more than cartographic design. The lesson is not that the project communicated poorly; it is that future entrants should make the communication object as visible as the method object. `uncertain-link`; `uncertain-inference`.[P3]

## Anti-patterns and omissions

- Public artifacts can exist and still remain hard to judge visually if indexed text is too thin or the map object itself is not recoverable in a readable form. That is part of why `CITIES [re]DEFINED` and `HARLEM, NYC` remain `partial` in the matrix despite sounding communication-oriented.[S7][P6][S1][P7]
- Method-heavy projects can under-communicate if the visual package is not exposed directly in the public-facing artifact.[P3]
- A future entrant should avoid titles that bury the claim. The title is part of the cartographic communication system, not separate from it.[P1][P2][P8]

## Win tactics

- Make the first screen or first page do argumentative work, not just decorative work.
- Choose the medium that best matches the claim: sequence when chronology or layered evidence matters, single bold visual object when prioritization or comparison matters.[P2][P5][P8]
- Use the title and subtitle to pre-load the reader with the right question.
- Keep map density proportional to the point being made.
- Ensure the public-facing artifact exposes the final communication object directly, not only a project abstract or CV line.[P3]

## Future-submission checklist

- Does the title help the map argue?
- Can a judge understand the project’s claim from the first visual or first screen?
- Is the medium chosen for rhetorical fit rather than convenience?
- Are maps and graphics carrying a clear analytical message?
- Would the project still be memorable after a fast skim?
