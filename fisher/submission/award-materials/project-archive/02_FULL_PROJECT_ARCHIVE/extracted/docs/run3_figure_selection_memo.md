## Final visual strategy

Use the figures in this order:

1. Global filtered residual corridor map.
2. Distance/residual model figure.
3. East/Southeast Asia focused case map.
4. Residual bridge score map.
5. Iberian/Atlantic-Pacific secondary case map.
6. Boundary/permeability figure as appendix or optional StoryMap expansion.

This ordering tells a clear Fisher story: broad screen, model logic, focused inference, geospatial-only insight, cautious secondary hypothesis.
