# Run 6 v3 Regional Balance Strategy

## The presentation problem
The project is methodologically global but the Run 6 v2 StoryMap could feel visually Asia-heavy. East/Southeast Asia is correctly used as the primary focused case, yet the sequence also includes an Asian topographic map and multiple Asian cuisine-pair vignettes. Without additional framing, a reviewer may incorrectly read the project as an Asia-only food geography project.

## Revised hierarchy
1. **Global method and discovery screen.** The project begins with all retained cuisines in the global prototype. The global layer identifies candidate residual corridors and motivates case selection.
2. **Methodological narrowing.** East/Southeast Asia is selected because it offers the strongest focused inference: a coherent regional geography, enough retained cuisine labels, meaningful residual links, and legible mainland/maritime structure.
3. **Mandatory non-Asia diagnostic comparison.** Iberian/Atlantic-Pacific residuals are included to demonstrate that the method also surfaces non-Asian long-distance corridor hypotheses.
4. **Europe/Atlantic caution.** Europe-linked and Atlantic-linked residuals are not elevated to the same status as East/Southeast Asia because existing outputs support them diagnostically, not as a full focused regional model.

## Required editorial moves
- Make the global discovery section more substantive and explicitly state that Asia is selected from the screen.
- Rename the Asia section to: **From global screen to focused case: why East/Southeast Asia carries the strongest inference**.
- Make the non-Asia diagnostic section mandatory, not optional.
- Add a callout: **Why Europe/Atlantic-linked material is diagnostic, not primary**.
- Use the secondary/limitations figure to support the non-Asia diagnostic and sensitivity discussion.

## Forbidden moves
- Do not imply a new Europe-specific analysis was performed.
- Do not invent specific pairwise numerical results for Europe or the Atlantic.
- Do not turn Iberian/Atlantic-Pacific patterns into causal trade, migration, or colonial claims.
- Do not demote the strongest evidence simply to look regionally balanced.

## Success criteria
The final StoryMap should read as: global GIS method → selected strongest focused case → non-Asia diagnostic comparison → disciplined limitations. It should not read as: Asia project with a token global map.
