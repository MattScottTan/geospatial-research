# Run 5 Topographic Corridor Interpretation

Created: 2026-05-01

## What the new map adds
Run 5 adds a more visually striking relief/coastal context to the East/Southeast Asia focused case. The Run 4 v2 figure already showed a corridor-accessibility proxy; the new map makes the physical geography more legible by displaying residual culinary links over relief, coastlines, islands, peninsulas, continental margins, and maritime space.

The most useful interpretive shift is visual rather than causal: a viewer can now see that the strongest residual links are not isolated table rows. Thai–Vietnamese appears as a compact mainland Southeast Asian link; Chinese–Korean appears as an East Asian mainland/peninsula link; Filipino links sit in a maritime/island context around the South China Sea and western Pacific.

## What the map supports
The map supports this final claim:

> In the East/Southeast Asia focused case, the strongest positive residual cuisine links become spatially interpretable when read against regional adjacency, coastal/island geography, and relief context.

This strengthens the Fisher spatial-necessity argument because the same ingredient matrix alone cannot show how residual links sit within coastlines, seas, islands, peninsulas, and terrain/barrier contexts.

## What the map does not prove
- It does not prove migration, trade, maritime exchange, colonial exchange, or terrain causality.
- It does not compute least-cost routes, slope, ruggedness, terrain friction, or historical travel paths.
- It does not replace the distance-residual model.
- It does not make the recipe corpus representative of all East/Southeast Asian food.

## Replace or supplement?
The Run 5 map should **supplement and visually upgrade** the Run 4 v2 topographic/corridor figure. It is more committee-ready and should be used as the main topographic/corridor visual. The Run 4 v2 figure can be retired from the main StoryMap/report or kept as a development-stage appendix.

## Recommended final use
Use `figures/final_revised/run5_east_se_asia_topographic_corridor_map.png` as a **main supporting figure** after the East/Southeast Asia case figure. Use `figures/final_revised/run5_corridor_callout_or_inset.png` only if there is room for an optional zoom/callout.
