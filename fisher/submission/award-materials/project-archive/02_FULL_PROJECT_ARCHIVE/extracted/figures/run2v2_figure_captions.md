# Run 2 v2 Figure Captions

Created: 2026-04-29

## `figures/run2v2_global_residual_corridor_map_filtered.png`

Filtered global residual corridor map. Lines connect the top positive residual cuisine pairs after generic-ingredient filtering and distance-only prediction. This is a global discovery figure: it shows candidate culinary corridors, not causal mechanisms.

## `figures/run2v2_east_southeast_asia_case_map.png`

Focused East/Southeast Asia case map. Lines show residual links among Chinese, Japanese, Korean, Thai, Vietnamese, and Filipino cuisines where available. This figure supports the strongest scoped interpretation because the cuisines form a coherent regional/cross-subregional spatial case.

## `figures/run2v2_iberian_atlantic_case_map.png`

Secondary Iberian/Atlantic-Pacific case map. Lines show residual links among Spanish, Brazilian, Mexican, Filipino, Cajun/Creole, Jamaican, and Southern U.S. cuisines. This case is useful as a corridor hypothesis but should be interpreted cautiously because of platform-bias and coarse mapping risk.

## `figures/run2v2_residual_bridge_score_map.png`

Place-level residual bridge score map. Point size represents long-distance positive residual bridge score. This is the strongest geospatial-only visual because it transforms pairwise food-similarity residuals into mapped spatial bridge roles.

## `figures/run2v2_geospatial_method_comparison.png`

Boundary/permeability proxy chart. It compares mean residuals by spatial boundary class, including same-subregion, same-region/cross-subregion, East/Southeast Asia cross-subregion, Iberian/Atlantic interregional, and other cross-region pairs. It is exploratory and should be used to motivate stronger GIS boundary/path modeling in Run 3.
