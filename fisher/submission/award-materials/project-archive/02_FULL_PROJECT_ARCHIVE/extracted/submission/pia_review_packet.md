## One-page project summary

**Project title:** Culinary Corridors: Mapping Food Similarity, Spatial Residuals, and Regional Exchange

This project treats cuisine as spatial evidence. It represents cuisines as ingredient profiles, computes pairwise similarity, compares that similarity with geographic distance, and maps positive residuals as candidate culinary corridors. The final submission uses a global 20-cuisine screen only for discovery. The strongest interpretation comes from a focused East/Southeast Asia case and from residual bridge scores that map which cuisines repeatedly participate in long-distance positive residual links.

The project is designed for the Howard T. Fisher Prize in GIS. Its core contribution is geospatial: it asks where cuisine similarity follows distance, where it breaks distance, and which places become bridge nodes in the residual geography.

## Scientific assumptions needing review

- Ingredient-profile similarity is a meaningful but limited proxy for culinary similarity.
- Generic pantry ingredients should be removed or downweighted for sensitivity analysis.
- Ingredient names can be normalized reproducibly, but ambiguous ingredients require food-science review.
- East/Southeast Asia is a reasonable focused case because the residual links are spatially coherent.
- Flavor chemistry should remain optional unless ingredient-to-compound matching is scientifically defensible.
- Fermentation should remain future work unless a strong geocoded microbiome dataset is available.
