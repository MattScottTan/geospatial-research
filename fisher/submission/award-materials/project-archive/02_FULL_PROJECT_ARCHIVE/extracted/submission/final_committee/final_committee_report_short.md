# Culinary Corridors - Committee Summary

Created: 2026-04-30

## Project question
When does cuisine similarity follow geographic distance, and when does it break distance-based expectation in ways that reveal candidate culinary corridors, bridge regions, or spatial boundary patterns?

## Core approach
The project represents cuisines as filtered ingredient profiles, computes pairwise similarity, maps cuisine labels to approximate geographic anchors, fits a distance baseline, and calculates residuals: observed similarity minus distance-predicted similarity. Positive residuals become candidate culinary corridors. The global model is a discovery screen; East/Southeast Asia is the strongest focused inference case.

## Main findings
- The filtered distance model shows that cuisine similarity decreases with log distance, but distance explains only part of the pattern.
- East/Southeast Asia provides the strongest scoped case, with high residual links such as Thai-Vietnamese and Chinese-Korean.
- The residual bridge index converts pairwise residual links into mapped place-level roles, making the result spatially necessary.
- Run 4 v2 adds a corridor-accessibility proxy showing that the strongest East/Southeast Asia residual links also sit in high-accessibility corridor contexts.

## Limitations
The recipe corpus is a proxy, not a census of world cuisine. Cuisine labels are approximate. Residual corridors are associations, not causal proof of migration, trade, colonialism, maritime exchange, or terrain effects. The Run 4 v2 corridor layer is a transparent proxy, not a formal topographic cost surface.
