# ArcGIS StoryMap Build Order — Culinary Corridors

Use this file as the construction checklist inside ArcGIS StoryMaps. Paste text from `storymap_copy_paste_script.md`; upload figures in the order listed in `storymap_figure_manifest.csv`.

**Important ArcGIS note:** Esri documentation says images can be added to the cover, body, sidecar panels, map tour panels, galleries, swipes, timelines, and more; images can be uploaded from your computer or linked from the web, but linked images cannot be used on the cover. Use uploaded image files for the cover and the six required figures.

## Recommended story type
- Use a **classic scrolling StoryMap** with image blocks and optional sidecar sections.
- Keep the text concise and let figures lead.
- Use the PDF as a backup link near the end, not as the main body of the StoryMap.

## Build sequence

### 1. Title / hero
- **Recommended block:** Cover block
- **Instruction:** Use project title, subtitle, author name, and hero image. If the hero figure is too dense for cover crop, use a clean title cover and place the hero image immediately below.

### 2. Research question and problem
- **Recommended block:** Text block + callout
- **Instruction:** Paste the research question, then add the “What changes when we add geography?” callout.

### 3. Data and caveats
- **Recommended block:** Text block + small caution callout
- **Instruction:** Explain recipe data, ingredient profiles, and caveats early.

### 4. Spatial method / residual logic
- **Recommended block:** Image block or sidecar
- **Instruction:** Upload Figure 2. Put method text before the image and caption under the image.

### 5. Global discovery screen
- **Recommended block:** Image block
- **Instruction:** Upload Figure 1 if not already used as cover. Label it as discovery, not proof.

### 6. East/Southeast Asia primary case
- **Recommended block:** Image block or sidecar
- **Instruction:** Upload Figure 3. This section carries the main focused inference.

### 7. Topographic corridor context
- **Recommended block:** Large image block
- **Instruction:** Upload Figure 4. Place it immediately after the East/Southeast Asia case. Optional: add the callout/inset image in a sidecar.

### 8. Residual bridge-index insight
- **Recommended block:** Image block
- **Instruction:** Upload Figure 5. Present it as the strongest GIS-only insight.

### 9. Secondary/diagnostic case and sensitivity
- **Recommended block:** Image block
- **Instruction:** Upload Figure 6. Keep language cautious.

### 10. Limitations and claim discipline
- **Recommended block:** Text block + callout
- **Instruction:** Use bullets. Make limitations visible and credible.

### 11. Conclusion and contribution
- **Recommended block:** Text block
- **Instruction:** End with the GIS contribution and final thesis.

### 12. Sources / PDF backup note
- **Recommended block:** Text block + button/link
- **Instruction:** Add source summary and link/mention the complete PDF backup.

## Suggested pacing
- Keep opening sections short: 2–4 paragraphs before the first method figure.
- Use callouts to carry the research question, key method, and claim cautions.
- Every figure section should answer: “What should the judge notice?”
- Avoid adding extra figures unless they clarify a specific step.
