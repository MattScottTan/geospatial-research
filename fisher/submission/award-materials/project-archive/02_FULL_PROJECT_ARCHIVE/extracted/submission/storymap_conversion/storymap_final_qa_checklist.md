# StoryMap Final QA Checklist

Use this checklist immediately before submission.

## Build checks
- [ ] Title reads: **Culinary Corridors**.
- [ ] Subtitle reads: **Mapping Food Similarity, Spatial Residuals, and Regional Exchange**.
- [ ] All six required figures are uploaded in the correct order.
- [ ] Optional Run 5 callout/inset is included only if it improves clarity.
- [ ] Every figure has a caption directly below it.
- [ ] Every figure has meaningful alt text where ArcGIS allows it.
- [ ] The Run 5 topographic map appears after the East/Southeast Asia section.
- [ ] The residual bridge-index figure appears after the Run 5 topographic context section.

## Claim checks
- [ ] Global map is described as discovery, not proof.
- [ ] East/Southeast Asia is described as the primary focused inference case.
- [ ] Run 5 topographic/relief map is described as spatial context, not causal proof.
- [ ] Residual bridge index is described as the strongest geospatial-only insight.
- [ ] No text claims that migration, trade, colonialism, maritime routes, or topography caused the results.
- [ ] No text claims the recipe corpus represents all world cuisine.
- [ ] No text treats cuisine labels as exact nation-state units.

## Source and limitation checks
- [ ] Limitations are visible before or near the results, not only at the very end.
- [ ] Final source/limitations panel is included.
- [ ] PDF backup is linked or mentioned in the final section.
- [ ] Any public/shareable PDF link opens outside your logged-in session.

## Visual checks
- [ ] StoryMap viewed on desktop.
- [ ] StoryMap viewed on mobile or narrow browser window.
- [ ] Dense figures remain readable or expandable.
- [ ] Cover image crop does not hide essential map content.
- [ ] Captions remain visible and not too long.
- [ ] Source text does not overwhelm the visual flow.

## Access checks
- [ ] StoryMap sharing setting is correct for the Fisher submission route.
- [ ] StoryMap opens in private/incognito browser.
- [ ] All embedded/linked images load.
- [ ] PDF link opens in private/incognito browser.
- [ ] Submission form accepts the StoryMap URL and/or PDF.

## Final submission checks
- [ ] Name, title, and affiliation are correct.
- [ ] Final abstract/description matches the one-page summary.
- [ ] Submit before the deadline.
- [ ] Save confirmation email or screenshot.
