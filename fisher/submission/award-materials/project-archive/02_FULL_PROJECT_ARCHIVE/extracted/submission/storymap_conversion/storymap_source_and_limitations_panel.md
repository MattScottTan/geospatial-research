# StoryMap Source and Limitations Panel

Use this as a final StoryMap section or collapsible-style source note.

## Source summary
This project uses a cuisine-labeled recipe/ingredient corpus as a prototype food dataset. The analytical pipeline normalizes ingredient names, filters or flags generic pantry ingredients, constructs cuisine-by-ingredient profiles, computes pairwise cuisine similarity, anchors cuisine labels to approximate geographic locations, models similarity against distance, and maps positive residuals as candidate culinary corridors.

The spatial outputs rely on cuisine-coordinate anchors, pairwise geographic distance, residual corridor results, East/Southeast Asia focused-case outputs, residual bridge-index summaries, boundary/permeability diagnostics, and a Run 5 shaded-relief map used as regional spatial context.

## Limitations
- The recipe corpus is platform-mediated and not globally representative.
- Cuisine labels are broad and do not map cleanly to nation-states.
- Cuisine anchors are approximate cultural-geographic reference points.
- Ingredient normalization and generic-ingredient filtering involve judgment.
- Positive residuals show spatial associations, not causal mechanisms.
- The East/Southeast Asia case supports the strongest interpretation, while the global map remains a discovery screen.
- The Run 5 topographic/relief map provides spatial context only; it is not a measured least-cost path, terrain-friction, historical route, or causal topographic model.

## Claim hierarchy
**Strong claims:** cuisine similarity is spatially structured; distance explains part but not all similarity; residuals identify candidate culinary corridors; residual bridge scores create a geospatial insight.

**Cautious claims:** some residual patterns are consistent with regional adjacency, corridor plausibility, maritime/coastal context, or exchange hypotheses.

**Do not claim:** migration, trade, colonialism, maritime movement, or topography caused the observed similarities; the dataset represents all world cuisine; cuisine labels equal countries.
