# Culinary Corridors — Complete Final Archive

This archive consolidates the materials used to build the final Fisher Award submission package for **Culinary Corridors**. It includes:

- final and intermediate StoryMap scripts, paste blocks, build orders, manifests, captions, QA checklists;
- final figures and all figure-development outputs, including the Run 5 East/Southeast Asia topographic corridor map and inset;
- final PDF reports, LaTeX sources, and source bundles;
- data tables, crosswalks, model outputs, residual-corridor outputs, topographic/corridor proxy outputs, and source manifests;
- scripts used to generate the analysis and figures;
- research/planning docs, claim audits, scorecards, limitations, source notes, and reproducibility logs;
- the uploaded Fisher strategy/playbook packet and the StoryMap exemplar PDF used as a style/depth reference.
