# Originality Longlist

Date: 2026-03-14 12:03 PM America/New_York

## Selection rule

Prototype exactly **two** originality packages, both tailored to this project rather than copied generically from the scouting memo. The goal is to find the option with the strongest visible payoff for an EIP StoryMap and final report.

## Prototype 1 — Compute Opportunity Bundle Index

### Question
Can the project move beyond raw distance-to-cloud and show a broader infrastructure-and-opportunity bundle at city scale?

### Proposed ingredients
- proximity to nearest cloud region
- provider diversity within regional reach
- cloud-region redundancy within regional reach
- city scale / market weight
- local institutional anchor signal from the project’s OpenAlex-linked city/institution files

### Minimal outputs required to judge it
1. one global bundle-index map
2. one figure comparing distance-only access vs. bundle score
3. one ranked outlier or top-city figure
4. one short method note and score table

### Why it fits this project
It directly addresses the project’s most mature conclusion: compute matters, but as part of a wider infrastructure bundle.

## Prototype 2 — Counterfactual Compute Siting Layer

### Question
If one additional compute node were added, which candidate city locations would reduce the largest weighted gap in urban compute access?

### Proposed ingredients
- current city frame and nearest-cloud distances
- city population as demand weight
- geodesic distance from candidate new nodes to all cities
- top candidate ranking by weighted reduction in distance gap

### Minimal outputs required to judge it
1. one map of top candidate cities
2. one ranked gain chart
3. one short method note and candidate table

### Why it fits this project
It turns the atlas into a planning/counterfactual tool and creates a visibly original policy-facing extension.

## Evaluation criteria for the downselect
Each prototype will be judged on:
1. novelty signal
2. visual payoff in StoryMap form
3. clarity to non-technical judges
4. fit with the project’s final claim
5. implementation risk / data dependence
