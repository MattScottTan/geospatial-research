  same visual prominence as the Gi\* finding. Do not bury it.

  consequence." A grep of the rendered PDFs for those words currently returns zero; keep it
  that way.
- **D-007** Add a row to `papers/CLAIMS.md` for every number that appears in a figure or
  caption.

# Relevant Memory

- matplotlib must use the `Agg` backend; `savefig('x.pdf')` gives vector output that
  `\includegraphics` embeds cleanly (verified).
- Read numbers from the committed JSON/CSV. **Do not recompute statistics inside the
  figure script** — that would create a second, unaudited provenance path.
- Key values, all in `reference_detail`: components 252 / 67; offsets +0.070 / −0.264;
  mean Gi\* z +0.142 / −0.566; cold 19→22 and 14→3; hot 7→6 and 0→1; Moran's I 0.0661
  with p 0.0085 free vs 0.0080 within-component.
- Prevalence: 39.4% of 1,764 configurations; 49.0% at k = 8; 0% by k = 40.

# Relevant Files / Artifacts

Write `papers/paper1/make_figures.py`, output into `papers/paper1/figures/`.

Figures needed (names are suggestions; the set is not):

1. **The split** — the 319 cities on a world map, coloured by component. Shows the two
   groups are geographically interleaved, not a simple east/west cut.
2. **The mechanism** — value distributions of the two components against the global mean,
   making the −0.264 offset visible.
3. **The artifact** — Gi\* z-score distributions by component under global standardisation,
   with the −1.96 threshold marked. The +0.142 vs −0.566 separation is the finding.
4. **The correction** — cold/hot counts per component, global vs within-component.
5. **Prevalence** — disconnection rate as a surface or heatmap over n and k, from
   `prevalence_by_n_k.csv`. Mark the conventional k = 8.
6. **The null result** — Moran's I null distributions, free vs within-component
   permutation, showing they essentially coincide. Required by D-009.

# Constraints

- One script, runnable standalone and idempotent.
- Vector PDF only. No rasterised panels, no screenshots.
- Colour-blind-safe palette; readable at print size; no reliance on colour alone to
  distinguish the two components (use marker or hatch as well).
- Every figure needs a caption-ready one-line description in the script, so T-008 does not
  have to invent one.
- Delete `placeholder.pdf` once real figures exist, and check nothing still references it.
