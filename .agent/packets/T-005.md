# Task

ID: T-005
Title: LaTeX build system and document scaffold
Objective: Create the build system and both document skeletons so that `make` produces two
compiling PDFs with working table of contents, bibliography, glossary and figure inclusion.

# Relevant Acceptance Criteria

- **AC-001** Both PDFs compile from committed source with zero errors and no unresolved
  references or citations.
- **AC-012** Each paper's structure separates exposition from contribution so a reader can
  locate the new result without reading linearly — enforced via a labelled section scheme
  and a table of contents.

# Dependencies

None. Build against placeholder content; other tasks fill it in.

# Relevant Decisions

- **D-001** LaTeX compiled to PDF is the deliverable. No Markdown.
- **D-005** **`.tex` files are authored with the Write/Edit tools, never Bash heredocs.**
  This environment's Git Bash collapses `\\` to `\` even inside quoted heredocs, silently
  corrupting tabulars. A smoke test failed with `Misplaced \noalign` before the cause was
  found. This is a hard constraint.
- **D-006** Two standalone PDFs sharing one primer source. `papers/shared/primer.tex` is
  `\input` into both; each paper must read independently.

# Relevant Memory

- MiKTeX 25.12, pdfTeX 4.23, latexmk 4.87. Verified working:
  `amsmath, amssymb, booktabs, graphicx, hyperref, natbib, geometry`.
- MiKTeX auto-installs missing packages on first use, so an initial compile may be slow.
  Prefer packages from the verified list; if you add one, compile to confirm it resolves.
- matplotlib with the `Agg` backend writes vector PDF that `\includegraphics` embeds
  cleanly — verified.
- Windows `MAX_PATH` applies; `core.longpaths` is set but keep paths short.

# Relevant Files / Artifacts

Create:
- `papers/Makefile` — `make` builds both PDFs; `make clean`; `make paper1`; `make paper2`.
- `papers/shared/preamble.tex` — shared packages, page geometry, theorem-like environments,
  a `\keyinsight{}` or similar environment for marking contributions.
- `papers/paper1/paper1.tex`, `papers/paper2/paper2.tex` — skeletons with the full section
  scaffold and `\input` of shared parts.
- `papers/shared/glossary.tex` — glossary mechanism (a simple `description` list keyed by
  `\label`/`\ref` is fine; avoid heavyweight glossary packages unless they compile first
  try).

Section scaffold each paper needs (placeholders acceptable at this stage):
abstract; introduction; primer (`\input` shared); the problem; the mechanism; evidence;
the correction; **a clearly titled contribution section**; **a clearly titled limitations
section**; annotated bibliography (`\input` shared); glossary.

# Constraints

  one — T-001 will overwrite it.
- Figures directories already exist: `papers/paper1/figures/`, `papers/paper2/figures/`.
  Include at least one placeholder figure so the graphics path is proven.
