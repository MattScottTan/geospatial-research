# Relevant Memory

Facts the figures must not contradict — all in `papers/CLAIMS.md`:

- **Union and first-significant are the same rule.** They coincide exactly. Do not plot
  them as two independent curves implying different behaviour; either plot one and say so,
  or plot both and annotate the coincidence.
- **The majority rule is conservative** — 1.9%–4.6% against 5% nominal. It sits *below* the
  nominal line. This is the most actionable result in the paper and should be visually
  unmissable, not a fourth line in a legend.
- **Inflation is not monotone in grid size.** Fine (7 values) gives 13.3%, standard (6)
  gives 14.3%, because correlation differs (0.714 vs 0.604). Any figure ordering grids by
  size must show this, not smooth it away.
- Observed atlas series under the published specification:
  k = 4, 6, 8, 12, 20, 40 → I = 0.0536, 0.0584, 0.0661, 0.0333, 0.0164, 0.0041;
  critical values 0.0546, 0.0449, 0.0387, 0.0317, 0.0242, 0.0158;
  significant at 3 of 6; arg-max is k = 8.
- matplotlib `Agg` backend; `savefig('x.pdf')` gives embeddable vector output.
- Read from committed JSON/CSV. **Do not recompute** — that creates an unaudited second
  provenance path.

# Relevant Files / Artifacts

Write `papers/paper2/make_figures.py`, output into `papers/paper2/figures/`.

Figures needed (names suggested; the set is not):

1. **The knob** — observed Moran's I against k on the atlas, with each k's own critical
   value overlaid, significant k values marked. Shows the statistic moving thirteen-fold
   and that 3 of 6 choices would have been called significant.
2. **What selection does** — the null distribution of the statistic under a fixed k versus
   under selection, so the shifted tail is visible.
3. **The inflation surface** — Type I error by rule across grids and n, with the 5% nominal
   line marked. The majority rule must be visibly *below* it.
4. **Why not Bonferroni** — observed union rate against the Bonferroni bound per grid, with
   mean inter-statistic correlation annotated. This is the explanatory figure: correlation,
   not grid size, governs the shortfall.
