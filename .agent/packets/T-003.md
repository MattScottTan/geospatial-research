# Relevant Memory

- The existing single-point result, which your work must reproduce as a correctness check:
  on the 319-city locations, grid k ∈ {4,6,8,12,20,40}, arg-max selection, 20,000
  replicates of iid N(0,1) with **no spatial structure** — false-positive rate **14.4%**
  against 5.0% nominal (2.9×). Mean inter-k correlation of Moran's I was **0.605**;
  independent tests would give the Bonferroni bound 26.5%.
- Per-k critical values from that run (95th percentile of I under the null):
  k=4: 0.0547, k=6: 0.0449, k=8: 0.0381, k=12: 0.0307, k=20: 0.0236, k=40: 0.0152.
- Moran's I is `(n/S0) * (z'Wz)/(z'z)` with `z = y - mean(y)`. Under an iid Gaussian null
  the null distribution can be obtained by Monte Carlo over `y`; weights are fixed per `k`,
  so build each `W` once and reuse.
- `esda.Moran` row-standardises by default — pass `transformation="O"` if used.
- Python 3.14; numpy 2.3.5, scipy 1.17.0, pandas 2.3.3 available.

# Constraints

- **At least three selection rules.** Suggested: (a) arg-max of Moran's I, (b) minimum
  p-value, (c) first `k` that reaches significance scanning upward, (d) a "robustness
  check" rule that reports significant only if a majority of grid values agree.
  Rule (d) matters: it is what careful practitioners believe they are doing, and its
  inflation is worth knowing.
- **At least two candidate grids** varying in coarseness and span — e.g. coarse
  {4,8,16,32}, fine {4,6,8,10,12,16,20}, wide {2,…,64}, narrow {6,8,10}.
- Vary `n` across at least three values.
- Report, alongside each inflation figure, the mean pairwise correlation between the
  statistics on that grid, and the corresponding Bonferroni bound — the gap between
  observed inflation and the Bonferroni bound is a central explanatory quantity.
- Monte Carlo standard error below 0.5 percentage points. At a rate near 0.14 this needs
  roughly ≥ 20,000 replicates per configuration; state the achieved SE.
- Explicit seed; deterministic re-runs.
- The null must be genuinely null: iid noise on real locations, no spatial structure.
